# jf_slixer

Минималистичный двух-дековый слайсер/пад-семплер для REAPER на JSFX. Нарезка по транзиентам или вручную, эвристическое распознавание kick/snare/hat/perc/crash, простые пофрагментные эффекты в духе Xfer Nerve, отзывчивый UI с плейхедом на каждый играющий слайс, MIDI/CC-выход per slice, импорт тейк-маркеров, две деки A/B с кроссфейдером, 4-канальный выход, 8 пресетов нарезки на деку.

## Файлы

- `jf_slixer.jsfx` — сам эффект. Скопировать в `REAPER/Effects/` (или подпапку), пересканировать FX-браузер.
- `jf_slixer_push_markers.lua` — companion-скрипт (Actions → Load ReaScript), публикует тейк-маркеры выделенного айтема в JSFX.

## Workflow

1. Повесь `jf_slixer` на трек с айтемом (или на трек, куда приходит аудио). Для 4-канального выхода поставь треку ≥4 канала (Track → Channels: 4).
2. Выбери деку (**A** / **B**) и запиши в неё аудио:
   - **REC** — мгновенная запись прямо сейчас (кнопка внутри плагина, транспорт не нужен);
   - **ARM** — арм: захват стартует сам с началом транспорта или по появлению сигнала (удобно для захвата айтема с его начала — тогда позиции тейк-маркеров совпадут).
   Остановка — повторное нажатие или достижение `Max capture`.
3. Нарезка — любым из трёх способов:
   - **DETECT** — по транзиентам (чувствительность — слайдер `Transient sensitivity`);
   - вручную: **двойной клик** по волне добавляет маркер, drag двигает, alt-клик/правый клик удаляет;
   - **тейк-маркеры**: выдели айтем, запусти `jf_slixer_push_markers.lua` — слайсы прилетят в активную деку автоматически (кнопка MARKERS — повторный импорт последней публикации). Захват должен быть сделан с начала айтема, чтобы позиции совпали.
4. **CLASSIFY** — раскладывает слайсы по классам KICK/SNARE/HAT/PERC/CRASH (эвристика: спектральные полосы + длительность затухания). Хэты автоматически получают choke-группу 1. Класс всегда можно поменять кликом в поле CLASS.
5. Играй с MIDI-контроллера. Дека A: `Deck A base note` (по умолчанию 36=C1), дека B: `Deck B base note` (84). У каждой деки свой фильтр MIDI-канала (OMNI/1–16) — можно повесить деки на разные контроллеры/каналы. Клик по паду — превью. У каждого играющего голоса — свой плейхед на волне и прогресс-бар на паде.

## Деки, кроссфейдер, выходы

- Тумблеры **A/B** переключают, какую деку показывает и редактирует UI (запись, нарезка, пресеты, параметры — всё уходит в активную деку). Обе деки звучат всегда.
- **Кроссфейдер** (equal-power) — оранжевый слайдер в шапке; двойной клик = центр. Он же — слайдер `Crossfade A-B`, доступен для автоматизации и MIDI-learn (для записи автоматизации крути слайдер, не UI).
- **OUT: MIX** — сумма A+B после кроссфейдера на каналы 1/2, копия деки B (пост-фейдер) на 3/4.
- **OUT: SPLIT** — дека A на 1/2, дека B на 3/4 (кроссфейдер продолжает действовать как две громкости). Дальше — штатный роутинг REAPER: посылы с каналов 3/4 на отдельный трек, свои цепочки обработки на каждую деку и т.д.

## Пресеты

8 слотов на деку (ряд `PRESET 1–8` в шапке): **клик** — загрузить, **shift+клик** — сохранить, **alt+клик** — очистить. Слот хранит нарезку и все per-slice параметры (питчи, эффекты, MIDI-out, choke, классы) — но не аудио: пресет ложится на текущий буфер деки, слайсы за пределами записи отбрасываются. Пресеты сохраняются в проекте.

## Per-slice параметры (нижняя панель, drag по вертикали, ctrl = точно, dblclick = сброс)

PITCH (±24 st) · GAIN · PAN · **FX** (клик циклит): OFF / CRUSH / STRETCH / COMP / FM / AM / RING / SAT · AMT · P2 (второй параметр эффекта: rate у крашера, размер грануляции у стретча, release у компрессора, частота у FM/AM/RING, тон у сатуратора) · CLASS · CHOKE (0 = нет, одинаковые группы глушат друг друга) · MIDI OUT · NUM · CHAN · BUS.

### MIDI/CC out per slice

MIDI OUT = NOTE: при триггере слайса шлётся note-on (velocity входящей ноты), note-off — по окончании голоса. MIDI OUT = CC: шлётся CC `NUM` со значением velocity. Канал и **MIDI-бас (1–16)** настраиваются per slice — дальше маршрутизируй штатным роутингом REAPER (track MIDI sends, пины плагинов ниже по цепочке).

## Глобальные режимы (футер + обычные слайдеры, доступны для автоматизации)

- **VOICES** Poly/Mono, **LEGATO** (в mono: без ретриггера огибающей), **GLIDE** 0–500 мс (портаменто питча в mono),
- **INTERP**: None / Linear / Hermite (4-точечная),
- **TRIG**: One-shot / Gate, **BASE A/B** и **CH A/B** (базовая нота и MIDI-канал активной деки),
- `Input passthrough` (вход проходит только на 1/2), `Master gain`, `Save audio in project` (сохраняет буферы обеих дек в проект — при длинных захватах проект тяжелеет).

## Честные ограничения (важно)

- **Élastique/растяжка REAPER**: JSFX не имеет API к риперным алгоритмам растяжки — они живут на уровне тейков, не плагинов. Внутренний STRETCH здесь — двухголовочный гранулярный time-domain (Hann-окна), питч и время независимы. Если нужна именно риперная растяжка — применяй её на айтеме до захвата (тогда jf_slixer захватит уже растянутый результат: это и есть способ «использовать риперные алгоритмы» в этой архитектуре).
- **Доступ к тейку**: JSFX не видит медиа-айтемы, поэтому аудио попадает внутрь через захват с трека, а тейк-маркеры — через Lua-мост (gmem). Зато всё сохраняется в проекте вместе с плагином.
- **Транспорт REAPER**: JSFX не может нажать record/play в самом REAPER — кнопка REC пишет во внутренний буфер плагина (что здесь и нужно).
- Классификация — быстрая эвристика, не ML: на «грязном» материале проверяй глазами (цвета маркеров) и правь кликом.

## CPU

Один проход по голосам в `@sample`, 16 голосов на деку, эффекты считаются только у активных. Детект/классификация/пересборка обзора волны идут чанками в UI-потоке и не трогают аудио. Буфер до ~170 c стерео на деку при 48 кГц.
